# CompTIA A+ Core 1 Exam Simulator

Ein Lern-Tool, das zur gezielten Vorbereitung auf die Zertifizierungsprüfung **CompTIA A+ Core 1 (220-1101)** geschrieben wurde. 

Dieses Projekt diente mir als praktische Übung, um Logik-Strukturen in der Programmierung zu vertiefen und gleichzeitig eine effiziente Lernumgebung für Hardware- und Netzwerkthemen zu schaffen.

## 🛠 Tech Stack
* **JSON**: Strukturierung und Speicherung der Fragen-Datenbank.
* **JavaScript**: Logik für die interaktive Benutzeroberfläche und die Auswertung der Antworten.
* **Python**: Skripte zur Datenaufbereitung und Validierung der JSON-Strukturen.
* **HTML/CSS**: Webbasiertes Interface zur Simulation der Prüfungsumgebung.

## 🚀 Features
* **Randomisierte Abfragen**: Simulation realer Prüfungsbedingungen durch zufällige Auswahl aus dem Fragenkatalog.
* **Instant Feedback**: Sofortige Validierung der Antworten zur Steigerung der Lerneffizienz.
* **Kategorisierung**: Gezieltes Training für spezifische Prüfungsbereiche (Hardware, Networking, Cloud Computing).
* **Statistiken**: Individuelle Statistiken und "Mastering Goals" per localStorage. 

## 👥 Collaboration & Success
Um den Lernerfolg innerhalb meiner Umschulungsklasse an der **Bildungsakademie Hannover** zu unterstützen, habe ich das Tool via GitHub Pages öffentlich zugänglich gemacht. 
* **Einsatz**: Das Tool wurde aktiv von meinen Kommilitonen zur Prüfungsvorbereitung genutzt.

## 📊 Proof of Concept (Personal Result)
Die Effektivität des Simulators spiegelt sich auch in meinem persönlichen Ergebnis wider: 
Am **26.03.2026** habe ich die CompTIA A+ Core 1 Zertifizierung mit **792/900 Punkten** abgeschlossen.
